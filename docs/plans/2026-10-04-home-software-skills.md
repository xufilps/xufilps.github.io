# 首页技能与软件

范围与文件：在 index.html 的“关于我”之后增加同级“技能与软件”区域，styles.css 增加简洁自动换行的软件列表样式。

内容：Blender、Rhino、KeyShot、Photoshop、SOLIDWORKS、Figma、Illustrator，按用户提供的顺序；不添加熟练度或额外能力声明。

验证：检查 HTML、七个条目和标题层级，预览桌面和手机宽度、明暗主题，git diff --check。提交合并到 main 后推送，核对 Pages 部署及线上内容。

风险与回滚：静态展示，影响范围仅首页；Git revert 回退功能提交。交付首页链接、线上截图和提交。
