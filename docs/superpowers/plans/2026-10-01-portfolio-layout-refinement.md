# 作品集页面布局调整记录

## 目标与范围

让首页、项目、文章和关于页形成统一的作品集体验。以 `xufilps` 的真实身份信息与作品内容为准；尚未提供的项目、文章和图片保留明确的待补充状态。

## 页面与视觉决策

1. 首页使用紧凑的身份区、主要内容列和联系信息侧栏，依次引导读者查看介绍、代表项目和思考记录。导航保持首页、文章、项目、关于四个入口，并提供 GitHub 链接。
2. 项目页、文章页和关于页分别提供适合后续填入真实内容的版式。项目和文章尚未发布时，显示清楚的空状态；关于页集中呈现已确认的个人介绍与联系方式。
3. `styles.css` 统一页面宽度、字体层级、分隔线、留白、浅色与深色配色及窄屏布局。`theme.js` 只负责主题切换，页面内容和导航不依赖脚本。
4. 头像在没有正式照片前使用本地占位图；不使用未经确认的肖像、经历、项目成果或联系方式填充页面。

## 验证与维护

- 检查四个页面各有一个主标题、导航当前页标识、有效的站内路径和清晰的键盘焦点；在桌面与手机宽度检查布局及横向溢出。
- 检查浅色与深色模式、主题选择的保存情况、图片加载和 JavaScript 关闭后的阅读与导航。
- 发布真实项目或文章时，核对标题、本人贡献、过程证据、结果、图片使用权限和链接，再替换相应的空状态。
- 修改后检查 Git 差异与 `git diff --check`；需要回退版式时，可从 Git 历史恢复对应提交。

## 后续细节调整

手机宽度下调整项目标题换行；首页和关于页共用本地头像占位图；关于页资料栏按教育、专业方向和所在地组织。继续以真实内容和可读性为准进行迭代。
